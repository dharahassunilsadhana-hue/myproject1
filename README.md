# Daily v7

Daily is a mobile-first student dashboard PWA for timetable, Wilma ICS sync, lesson renaming, lesson timers/notifications, and HSL journey handoff.

## Deploy to Vercel

Import this GitHub repository into Vercel. No build command is required; the project is a static PWA with Vercel serverless functions under `api/`.

## v7

- Persistent lesson renaming
- Duplicate ICS lesson filtering
- ICS file and URL import/sync
- Exact imported lesson times
- Timetable removal
- Lesson end countdowns and local notifications while the app is active
- HSL universal-link handoff
- PWA manifest/service worker
- Branded Daily home-screen icons
